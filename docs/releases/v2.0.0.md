# CPU-LLM v2.0.0 (stable)

Released 2026-10-29 from `release/v2`. v1 (`/v1`) stays available as the
previous stable and keeps receiving fixes on `release/v1`.

## What is new

v2 adds a design, planning and insights lab on top of the v1 tuning platform.
The feature list, with the engineering problems each feature answers and the
sources behind them, is in [docs/versions/v2/features.md](../versions/v2/features.md)
(served at `/v2/features/`).

- **Designer** (tab): die/cache/NUMA-level CPU designer with projected decode
  speed, TTFT, energy, fit and cache residency; roofline with DRAM, L3, vector
  and matrix ceilings; design-space grid; sweeps; compare; scale-out planner;
  "Ask the advisor".
- **Planner** (tab): NUMA placement, thread count, serving concurrency with KV
  memory and the compute knee, quantisation pay-off per precision, cost per
  million tokens and break-even volume.
- **Insights** (tab): calibration of projections against measured runs (apply
  the achieved efficiency with one click), noise and significance per run,
  predictor for unmeasured machines (calibrated model + nearest measured
  runs), benchmark matrix, Claude advisor.
- **AI advisor** (server): `POST /api/ai/ask` proxies to the Anthropic API with
  the admin-stored key; `Admin → AI advisor` configures key, on/off, model,
  effort and answer length. Off until a key is added.
- **Agent:** memory bandwidth is now the better of a multi-threaded streaming
  read and a copy (`memory_bandwidth_gbs`), with both figures kept.
- **Versioned site:** `/v1` previous stable, `/v2` stable (`/` redirects
  here), `/v3` preview; version bar labels updated.

## Library

- `frontend/src/lib/archmodel.js`: `placements`, `threadSweep`, `serving`,
  `roofline`, `quantAdvice`, `cost`, `explore`, `calibrate`, `projectTps`.
- `frontend/src/lib/stats.js`: mean/sd/percentiles, 95% CI, significance
  against a noise band, OLS, Pearson, MAPE, power-law fit, distance-weighted
  k-NN.
- `frontend/src/lib/designs.js`: design library and calibration storage shared
  by the v2 tabs.

## Tests

## Upgrade notes

- No new environment variables. The Anthropic key is set in Admin, not in env.
- `@anthropic-ai/sdk` is a new server dependency (installed by `npm install`
  during the Hostinger build).
- Agents re-register with the new bandwidth figure on their next start; older
  measurements in finished runs are kept as recorded.
