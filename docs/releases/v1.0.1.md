# CPU-LLM v1.0.1 (stable)

Released 2026-10-29. Fix release on `release/v1`.

## Fixes

- **Offline machines:** the Tune tab showed a disabled "Machine offline"
  button. It now explains that a machine is switched on by starting its agent
  (command in Admin → Agents) and lets you **queue** the run; it starts as
  soon as the machine connects. A queued run can be deleted from Runs.

## Changes

- The site is versioned: **/v1** is stable, **/v2** is the preview of new
  features, and each has a feature page (`/v1/features/`). A thin bar at the
  top links them. Old links to `/` go to the stable version.
- Builds never include source maps.

## Note on tags

The `v1.0.0` git tag points at an older commit by mistake; the code that was
deployed as 1.0.0 is merge commit `1909002` on `main`. Use `v1.0.1` or later.
