# CPU-LLM v3.0.0 (stable)

Released 2026-10-29 from `release/v3`. v2 (`/v2`) is the previous stable, v1
(`/v1`) is archived but still served; both keep receiving fixes on their
release branches.

## What is new

Feature page: [docs/versions/v3/features.md](../versions/v3/features.md)
(served at `/v3/features/`). Roadmap to v5: [docs/ROADMAP.md](../ROADMAP.md).

- **Campaigns** tab: machines × models with one preset; per-machine queues
  (up to 20 queued; the one-run-per-machine rule is gone); progress; result
  matrix with best tok/s per cell and ▲/▼/• regression verdicts against the
  most recent earlier run of the same cell (band = max of both noise
  estimates, ≥ 3%); CSV export; delete with or without its runs.
- **Exports:** `/api/jobs/{id}/export.json`, `/api/export/runs.csv`,
  `/api/campaigns/{id}/export.csv`; links on Runs and Campaigns.
- **Audit log:** `DATA_DIR/audit.log` (JSON lines) written by middleware for
  every non-GET API call with actor, IP, method, path, status and a
  secret-free summary; `GET /api/admin/audit`; Admin → Audit log.
- **Operations:** `/metrics` (Prometheus), `/api/openapi.json` (OpenAPI 3.0),
  `/api/health` with version; `docs/API.md`.
- **Live forecast:** Machines → telemetry draws the next minute of CPU and
  memory (Holt smoothing over the rolling window) with a band.
- **Measure it** from the Planner (shipped first as the v3 preview).
- **Agent:** `usable_cores` from CPU affinity; thread sweeps respect cpusets.
- Server: a run summary no longer breaks the listing when a result lacks a
  recipe.

## Tests

Server 25 (admin, AI, app lifecycle, campaigns/metrics/openapi/audit,
install, site), frontend 28 (perf model, architecture model, statistics,
forecast).

## Upgrade notes

- No new environment variables. `campaigns.json` and `audit.log` appear in
  `DATA_DIR`.
- Dashboards that assumed one run per machine should expect queues.
- v4 preview lives at `/v4` (plan: benchmark suite for open-source CPU/GPU
  workloads, power optimiser with RAPL and dynamic core control, fleet tab).
