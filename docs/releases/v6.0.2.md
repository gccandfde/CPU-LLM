# CPU-LLM v6.0.2 (stable)

Released 2026-11-01 from `release/v6`. Patch on [v6.0.1](v6.0.1.md).

- **Dedicated data folder, enforced.** CPU-LLM keeps all of its state in its
  own `DATA_DIR` and nowhere else. On first start it stamps the folder with
  `app-identity.json`; any later start refuses a folder stamped by another
  app or holding another app's files, so data can never mix with another
  product on the same host even if `DATA_DIR` is set wrong
  (`server/src/identity.js`). Backup bundles and restore are unchanged.
